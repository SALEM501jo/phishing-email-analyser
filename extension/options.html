What this extension sends, and where

When you open an email in Gmail, the extension sends it to the analyser server you configure below, and nowhere else.
  • Full mode (default) sends the subject, sender, body text, links and attachment names.
  • Privacy mode sends everything except the body text. The body never leaves your browser.
  • Attachments and images are never uploaded. QR codes are decoded here in the browser.
  • The server doesn't store email content. It logs only the verdict.
  • The server looks up the domains in the email (registration date, blocklists), never the content.

Server

Your self-hosted analyser, e.g. https://phishing.example.com. HTTPS is required for anything other than localhost. Only needed if the server sets ApiKey. Stored in the extension, never exposed to Gmail's page.

Privacy

Diagnostics

How the extension read the last email (which strategy found each part). No email content is shown or stored. If Gmail changes its layout, this shows which part broke. Include it when reporting a problem.
